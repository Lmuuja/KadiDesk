# KadiDesk - Admin & User Management Dashboard

KadiDesk is a modern, responsive full-stack admin dashboard built with Node.js, Express, MongoDB, and EJS. It features complete authentication, session management, user/customer management, and dark/light mode toggle.

## 🚀 Features

- **Authentication & Authorization:** Secure login/logout using `express-session` and `connect-mongo`.
- **Role-Based Access Control:** Superadmin, Admin, and User roles with restricted permissions.
- **Customer & User Management:** Full CRUD operations for managing customer records and user permissions.
- **Dark & Light Mode:** Seamless theme switching with system state persistence.
- **Responsive UI:** Custom sidebar and navbar styled with Bootstrap 5.

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Templating Engine:** EJS
- **Frontend/Styling:** Bootstrap 5, Bootstrap Icons, Custom CSS
- **Authentication:** Session-based authentication (`express-session`, `connect-mongo`)
